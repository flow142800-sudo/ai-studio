# AI Studio – AI Image & Video Generator

AI Studio is an AI-powered web application built with Next.js that allows users to generate images and videos from text prompts.

## Features

- AI Image Generation
- AI Video Generation
- Multiple image generation
- Image aspect ratio selection
- Video aspect ratio selection
- Pollinations AI integration
- Google login with Firebase
- Download generated images and videos
- Modern responsive interface

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Firebase Authentication
- Pollinations AI

## Requirements

Before running the project, make sure you have:

- Node.js installed
- A Pollinations account/API access
- A Firebase project if you want to use Google login
